# Font asset provenance

This directory is the Chromix Windows-persona font bundle. The bundle is
assembled from the supplied Windows font files and retains their original
filenames and OpenType family metadata. Duplicate files are intentionally
preserved because some callers and font-enumeration checks address the
original Windows filenames.

The supported runtime formats are TrueType/OpenType `.ttf` and TrueType
Collections `.ttc`. Legacy `.fon` files are retained as source assets but are
not copied into the Linux runtime bundle because Fontconfig and Chromium's
modern font loader do not reliably enumerate them as OpenType families.

The files are not generated by Chromix. Their redistribution terms remain the
responsibility of the source/provider of the supplied assets. Do not treat
this file as a license grant; retain any upstream license or notice that
accompanied the assets.
